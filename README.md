# Part 2 — Coding Technique Exploration

## Particle Systems + Perlin Noise Motion

A useful coding technique for recreating this effect is a particle system combined with Perlin noise animation. Particle systems can generate thousands of moving points or shapes, while Perlin noise creates smooth organic motion instead of random movement. Together, they can simulate flowing energy, fog, or biological distortion similar to the visuals in *Annihilation*.
